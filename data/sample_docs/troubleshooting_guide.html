Troubleshooting Guide

SYNTHETIC sample document created by the team for development and testing. Orbitly Inc. is a fictional company. Last updated: 2026-09-12.

Error codes

ERR-401 Session expired

Your sign-in token has expired. Sign in again. If it happens repeatedly, check that your device clock is correct.

ERR-403 SSO configuration error

The identity provider rejected the SAML response. Ask an Admin to verify the Entity ID and the signing certificate in Admin > Security > Single sign-on. Certificates must not be expired.

ERR-429 Too many requests

You exceeded the API rate limit for your plan. Wait for the time given in the Retry-After header, then retry with exponential backoff.

ERR-503 Service unavailable

The service is under scheduled maintenance or experiencing an incident. Check the status page before contacting support.

Desktop app does not sync

First confirm you are on the latest desktop version from Help > Check for updates. Then sign out and sign in again. If files still do not sync, clear the local cache from Settings > Advanced > Clear cache. Clearing the cache does not delete files stored in the cloud.

Uploads fail

Uploads fail when a file exceeds the maximum upload size of 100 MB, or when the workspace storage quota is full. Owners can view storage usage under Billing > Usage.

Contacting support

Open a ticket from Help > Contact support and include the error code, the time it happened and your browser version.
