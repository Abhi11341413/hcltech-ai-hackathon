Integrations Configuration

SYNTHETIC sample document created by the team for development and testing. Orbitly Inc. is a fictional company. Applies to version 3.0.

Slack

Admins connect Slack from Admin > Integrations > Slack > Connect. Choose which channels receive project notifications. Members can mute notifications per project.

Jira

The Jira integration links Orbitly projects to Jira Cloud projects. Jira Server and Data Center are not supported. Status changes sync in both directions every 5 minutes.

Webhooks

Create webhooks under Admin > Integrations > Webhooks. Each workspace can have up to 20 webhooks. Payloads are signed with HMAC-SHA256 using the webhook secret; verify the X-Orbitly-Signature header.

If your endpoint does not return HTTP 2xx within 10 seconds, the delivery is retried up to 5 times with exponential backoff (1, 2, 4, 8 and 16 minutes). After the final failure the webhook is disabled and Admins receive an email.

API keys

Create API keys from Settings > Developer > API keys. Keys inherit the permissions of the user who created them. Keys that are not used for 90 days are revoked automatically.
