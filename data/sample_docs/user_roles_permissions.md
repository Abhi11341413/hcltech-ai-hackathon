# User Roles and Permissions

> SYNTHETIC sample document created by the team for development and testing.
> Orbitly Inc. is a fictional company. Last updated: 2026-05-20.

## Role overview

Orbitly Workspace has four roles: Owner, Admin, Member and Guest.
Each workspace has exactly one Owner. Ownership can be transferred from Admin > Settings > Transfer ownership.

## Owner

The Owner can manage billing, delete the workspace, transfer ownership and do everything an Admin can do.

## Admin

Admins can invite and remove users, change roles (except the Owner), configure SSO and view audit logs.
Admins cannot see or change payment methods.

## Member

Members can create projects, upload files and invite Guests to projects they own.

## Guest

Guests can only access projects they are explicitly invited to.
Guests cannot invite other users, create projects or export data.
Guest accounts do not count towards paid seats, up to a maximum of 5 guests per paid seat.

## Changing a role

Go to Admin > Users, select the user and choose Change role. Role changes take effect immediately
and are recorded in the audit log.
